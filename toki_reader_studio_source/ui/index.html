STATIC READER

배포용 리더 만들기

저장한 이미지를 세로 스크롤 웹 리더 형태로 복사합니다. 결과 폴더에는 HTML, CSS, JavaScript, 이미지와 Vercel 설정이 포함됩니다.

아직 내보낸 작품이 없습니다.
DEPLOY

배포 구조

  1. 앱에서 배포용 폴더를 생성합니다.
  2. 해당 폴더를 별도 GitHub 저장소에 올립니다.
  3. Vercel에서 저장소를 Import합니다.
  4. 프레임워크는 Other, 빌드 명령은 비워 둡니다.

공개 배포는 제작자 또는 권리자가 허용한 범위에서만 진행해야 합니다.
